# @zhoumingrui/plugin-mail-center

An independently developed NocoBase mail center with multi-account IMAP/SMTP synchronization and incoming-mail workflow triggers.

The plugin provides mailbox management, inbox/outbox/draft/archive/trash views, message composition, attachments, labels, templates, signatures, synchronization audit logs, and a `mail-received` workflow trigger.
